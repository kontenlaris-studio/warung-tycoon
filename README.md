# Warung Tycoon — idle game

Build a warung empire from one coffee cart to a café chain. Click to serve, buy income assets, earn while away (50%, capped at 8h), and prestige into new branches for a permanent +25% each. Zero dependencies, one HTML file, progress saved locally.

**Play:** https://kontenlaris-studio.github.io/warung-tycoon/
